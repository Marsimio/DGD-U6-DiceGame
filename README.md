# Dice Game

An assignment project developed for **Digital Games Development** using Unity. This project marked my first experience using **ProBuilder** for level design, creating more advanced **enemies**, **Cinemachine** for camera controls, and **UI Toolkit (UI Documents)** to create a skill tree system.

The game features combat, enemy interactions, a map view, a skill tree, and a shop system.

## Controls

| Key | Action |
|---|---|
| **WASD** | Move player |
| **Mouse** | Move player camera |
| **Left Click** | Attack |
| **C** | Clear enemies |
| **M** | Toggle map view |
| **Q** | Open skill tree menu |
| **X** | Open shop |
